# Portfolio

Bu, kendi kişisel portfolyo sitem. Deneyimlerimi, yeteneklerimi ve üzerinde çalıştığım projeleri tek bir yerde toplamak için hazırladım.

## Teknoloji Yığını

Next.js (App Router) · React · TypeScript · Tailwind CSS v4 · Lucide

## Kurulum

```bash
npm install
npm run dev   # http://localhost:3000
```

## Projeler

Site içeriği (profil, projeler, deneyim, yetenekler) tek dosyada: `src/content/site.ts`. Projeler [GitHub profilimdeki](https://github.com/ahmetkurtbm) public depolar ve canlı demolarıdır: GastroFlow, TestMetrix, ReceiptFlow, GateHub, Diyetgo, Question to Test, Pusula Aktivite Merkezi.

## Açık kaynak katkıları

Başkalarının projelerine yaptığım katkılar sitede "Açık kaynak" bölümünde, veri olarak `src/content/site.ts` içindeki `contributions` listesinde durur.
